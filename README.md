# E Jayanth Madhav — Portfolio

Personal portfolio and showcase of engineering projects, LLM systems, and developer tooling.

## About Me

I'm **E Jayanth Madhav**, an **Associate Software Engineer at Cubic** based in Hyderabad, India. I specialize in building modern full-stack web platforms, enterprise LLM gateways, and autonomous AI agents.

### Highlights:
- **Associate Software Engineer at Cubic**: Engineered enterprise LLM gateways for unified access to internal **Qwen** foundation models. Developed autonomous **AI PR Review Agents** deployed on **NVIDIA H200 GPUs (140GB VRAM)**, and built a unified **Release Management Automation Platform** with **Next.js**, **Node.js**, and **Playwright**.
- **Open Source & Core Developer**: Maintainer at **Helixque (HXQLabs)**, architecting scalable 1:1 video networking infrastructure with WebRTC and Socket.io.
- **Published Researcher**: Research papers published with **Springer Nature** (Federated Learning & GANs for MRI tumor detection) and **ICICT '24** (Time-series retail demand forecasting with ARIMA).

- **AI & LLM Systems**: Qwen 40B+ LLM, LLM Gateway, AI PR Review Agents, NVIDIA H200 (140GB VRAM), TensorFlow, Scikit-learn
